# GOLD 多週期資料接線

## 架構

`可信已收盤 M1 bid/ask + 收到時間 + 證據指紋 → ClosedMinuteBuffer → M1/M5/H1 → MarketFrame`

`timeframes.py` 重用既有 `replay.aggregate`，只聚合 UTC 對齊、完整且連續的分鐘資料。
bid／ask 分開儲存及聚合；交叉價格或非 GOLD 輸入拒絕。

- `ClosedMinute`：明確收盤端點、收到時間、商品及證據。`closure_verified` 預設 false。
  這是可信上游的驗證結果，不是僅憑 hash 或布林值就能證明來源；原始 snapshotTimeUTC
  不得在語義未證實時直接改名為 close timestamp。
- `ingest`：允許亂序回補但保留可用時間；相同棒不改首次收到時間。
  價格修訂衝突後緩衝區持續不合格，需以核對資料重建，不默默覆寫歷史。
- `snapshot(now)`：只選收盤及接收时间均不晚於 now 的資料，晚到回補不污染過去決策。
  不補缺棒、不用 mid／固定價差補 ask。只有完整窗口才標記 ready。
- `frame`：輸出既有 PaperService 可用的 MarketFrame；價格分析沿用 bid，
  ask 聚合保留於 snapshot。以最近 12 根完整 M5 算一小時區間。
  不覆寫上游時段、價差、時鐘、預算等限制；上游 data_complete=false 仍是 false。
- H1 保留最近連續最多 24 根，至少 3 根；M5 取連續 12 根，M1 取連續 2 根。
  較早缺口不會永遠污染後來完整窗口。分鐘記憶體有上限，預設 2880 根。
