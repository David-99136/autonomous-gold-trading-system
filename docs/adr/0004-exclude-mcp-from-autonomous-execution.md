# Exclude Capital.com MCP from autonomous execution

Capital.com's official MCP requires user confirmation for each trade and therefore cannot implement the agreed unattended Trading Agent. The Demo gateway will target the Public API behind the independent Risk Envelope, while any Live use remains blocked until the user's contracting entity confirms in writing that this form of automation is permitted; if it is not permitted, the system remains Demo-only or changes to human-confirmed execution.
