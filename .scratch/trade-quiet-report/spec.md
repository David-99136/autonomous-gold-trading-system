# 交易精簡回報

Status: resolved
Type: task

## Scope

2026-09-20 使用者要求繼續非策略工作，黃金策略驗證延後至 2026-09-21（星期一）；
本輪處理主規格 §14 的 AI 對話技能。星期一仍須驗證開市、資料品質及既有授權，
不是預約自動啟動或放寬策略／實盤門檻。

僅回報已確認開單（區分掛單與成交）、部分／全平倉、撤單及每日總結。
保留風控故障、未知訂單結果及必要授權告警。完整稽核不減少。

## Acceptance

- NO_TRADE、心跳、正常對帳：不逐筆回覆。
- 掛單受理：不能寫成已成交；撤單逾時：不能寫成已撤單。
- 部分平倉：保留剩餘數量，損益缺失寫待核對。
- 熔斷或停損狀態不明：立即告警，不延到日結。
- 日結資料不完整：暫結並列未知，不把 AI 成本或部位補零。
- 開發或使用者主動問進度：正常簡短回答。
