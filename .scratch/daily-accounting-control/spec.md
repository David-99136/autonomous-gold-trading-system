## 本輪實作範圍

1. 依明確含時區的起點、截至時間、模式及帳戶彙總已核對平倉分段。
2. 精確費用補證獨立持久化；缺費用不補零。收到權威帳務的成交清單、淨損益、
   日初權益與證據指紋後才出具匹配 receipt。空帳本不代表零交易。
3. receipt 綁定當期帳本摘要；晚到分段或費用更新使舊 receipt 失效。
4. 協調器直接讀有效 receipt，不能用使用者對話、浮虧或 Paper 損益觸發 Demo。
   日初權益固定、截至時間不能倒退；软熔斷當日保持，硬鎖不因跨日解除。
5. 10%：落盤封鎖新進場 → 一次性減風險並確認空倉／零掛單 → 串列 session
   邊界內重新認證 → 新 session 同帳戶對帳 → 保留硬鎖。
6. 一般交易及 3% 不呼叫重新認證；任一步不明或程序中斷留下持久化待恢復，
   不自動重送訂單或重跑換 session。通知失敗不影響風控。
